01 · Architecture

Chọn mode phù hợp với source code.

Hosted · Streamable HTTP

Người dùng chỉ thêm MCP endpoint và xác thực Cloudflare trong browser. Server ở Cloudflare Workers; source phải là GitHub public đã có build output.

Local · stdio

MCP chạy trên máy người dùng, đọc ./dist, assets và build output local trực tiếp. Dùng khi repo private hoặc cần tự build React/Vite.

Remote MCP không thể đọc filesystem máy người dùng. Hosted mode không chạy npm install hay build scripts từ repo; quy trình đó không an toàn trong multi-tenant Worker.

02 · Hosted Worker

Provision endpoint remote.

  1. Đăng nhập Cloudflare account để triển khai Worker. Tạo API token triển khai riêng có Account → Workers Scripts → Edit. Nếu dùng CLI, đặt CLOUDFLARE_API_TOKEN và CLOUDFLARE_ACCOUNT_ID trong shell hoặc GitHub Actions secrets; không commit secrets.
  2. Tạo KV namespace cho OAuth grants: npx wrangler kv namespace create OAUTH_KV. Thay hai ID mẫu trong remote/wrangler.jsonc bằng ID production và preview vừa tạo.
  3. Kiểm tra Worker build mà chưa deploy: npx wrangler deploy --config remote/wrangler.jsonc --dry-run.
  4. Deploy Worker: npx wrangler deploy --config remote/wrangler.jsonc. Endpoint là https://mcp-cloud-deploy-server.<account-subdomain>.workers.dev/mcp. OAuth issuer và resource metadata được dựng theo origin của Worker.
  5. Thay placeholder endpoint ở public/index.html bằng URL Worker thật, sau đó deploy website Pages. MCP clients cần endpoint chính xác có path /mcp.
CẤU HÌNH WRANGLER (được lưu trong repo)
remote/index.ts          # OAuthProvider + MCP tools
remote/wrangler.jsonc    # Worker + OAUTH_KV binding
CLOUDFLARE_API_TOKEN     # deploy credential — environment only
CLOUDFLARE_ACCOUNT_ID    # account đích

Deployment token của maintainer và API Token của từng user là hai credential khác nhau. Không đưa deployment token vào OAuth properties, trình duyệt hay cấu hình MCP.

03 · Local stdio

Chạy server local từ source.

LOCAL SETUP
git clone https://github.com/hoangtrietdev/cloudflare-mcp.git
cd cloudflare-mcp
npm ci
cp .env.example .env
# Điền CLOUDFLARE_API_TOKEN và CLOUDFLARE_ACCOUNT_ID trong .env
npm run build
npm start

File .env bị Git ignore. MCP host khởi chạy scripts/start-local.mjs để load dotenv rồi mở stdio. Dùng config mẫu đã tạo trong examples/configs/ cho Codex, VS Code, Claude Desktop và JetBrains.

Local mode dùng deploy_to_cloudflare_pages với dir_path trỏ tới output đã build, ví dụ ./dist. Với React/Vite SPA, bật spa_mode: true.

04 · OAuth & credentials

Token riêng theo từng người dùng.

Hosted Worker dùng @cloudflare/workers-oauth-provider với authorization code + PKCE, consent CSRF binding và OAuth revocation. Trong browser consent, user nhập Cloudflare Account ID và API Token; server kiểm tra token qua /user/tokens/verify và xác minh quyền Pages.

  • OAuth provider lưu grant props mã hóa trong Cloudflare KV. API Token không xuất hiện trong MCP tool input/output hay logs.
  • Token tối thiểu cho deploy: Account → Cloudflare Pages → Edit.
  • Gắn domain tự động cần thêm Zone → Zone → Read và Zone → DNS → Edit, scoped vào các zone cần thiết.
  • Token OAuth và token Cloudflare tách biệt. Ngắt MCP grant/revoke OAuth để thu hồi connector; thu hồi API Token trong Cloudflare để vô hiệu hóa credential upstream.

Token Cloudflare được truyền qua HTTPS tới Worker để lưu encrypted-at-rest và sử dụng cho API calls. Người dùng phải tin cậy publisher/server; cần có privacy policy và quy trình xử lý sự cố trước khi mở endpoint rộng rãi.

05 · Tool contracts

Hosted source phải là static build sẵn.

ToolHosted inputs / behavior
deploy_to_cloudflare_pagesproject_name, repo_url, branch, output_dir, spa_mode. Chỉ fetch GitHub public zipball; thư mục output phải có index.html.
attach_custom_domainBind domain, tạo proxied CNAME nếu zone có trong Cloudflare account và không có record xung đột.
list_deploymentsTrả trạng thái 10 deployment gần nhất và domain bindings.
  • Đặt static output đã build sẵn trong repo, ví dụ dist/. Nếu project React/Vite, CI của repo người dùng cần build trước và publish artifact vào branch/folder đã chọn.
  • Private repositories không hỗ trợ trong hosted mode. Không gửi GitHub PAT hoặc credential qua MCP tool.
  • Giới hạn hosted mode: archive nén tối đa 20 MiB, tổng output tối đa 50 MiB, mỗi asset tối đa 10 MiB, tối đa 20.000 files.
  • Archive chỉ tải từ api.github.com và redirect codeload.github.com; path traversal bị từ chối.
06 · Development & CI

Kiểm tra trước khi thay đổi.

LOCAL CHECKS
npm ci
npm test
npx tsc -p tsconfig.remote.json
npx wrangler deploy --config remote/wrangler.jsonc --dry-run

CI kiểm tra package local trên Node.js 18, 20 và 22; trên Node.js 22, CI typecheck Worker và build dry-run. Online deployment tách riêng khỏi CI thường ngày để PR không tự ý thay đổi production Worker.

Không ghi token, account payload, request body hoặc authorization headers vào logs. Error messages phải trả hướng khắc phục mà không phản chiếu secret. Xem chính sách quyền riêng tư.
