Run MCP locally.

For developers who want a dedicated stdio MCP process on their own machine. The server reads local build folders and loads Cloudflare credentials from an ignored .env file.

01 · Setup

Install and build from source.

  1. Install Node.js 18 or later and npm.
  2. Clone the repository, install dependencies, create your private .env file, then compile TypeScript.
TERMINAL · MACOS / LINUX / WSL
git clone https://github.com/hoangtrietdev/cloudflare-mcp.git
cd cloudflare-mcp
npm ci
cp .env.example .env
npm run build

On Windows PowerShell, use Copy-Item .env.example .env for the copy step.

02 · Cloudflare access

Create a narrowly scoped API Token.

  1. In Cloudflare Dashboard, open My Profile → API Tokens → Create Token.
  2. Choose Pages Edit for the specific Cloudflare account.
  3. Add Zone Read and DNS Edit only when you want automatic DNS changes for custom domains.
  4. Copy your Account ID from the account overview, then enter both values in .env.
.ENV · LOCAL ONLY · NEVER COMMIT
CLOUDFLARE_API_TOKEN=your_scoped_api_token
CLOUDFLARE_ACCOUNT_ID=your_cloudflare_account_id

Use an API Token, never the Global API Key. Keep .env private and revoke the token if you suspect exposure.

03 · MCP client

Point your client at the local process.

Replace /absolute/path/to/cloudflare-mcp with your checkout path. Ready-to-edit examples are in examples/configs/.

Codex

Merge examples/configs/codex.toml into ~/.codex/config.toml and restart Codex.

VS Code

Copy examples/configs/vscode.mcp.json to your workspace .vscode/mcp.json and update the absolute path.

Claude Desktop

Merge examples/configs/claude_desktop.json into Claude Desktop’s MCP config. On macOS it is usually under ~/Library/Application Support/Claude/.

JetBrains

Import examples/configs/jetbrains.json from AI Assistant → Model Context Protocol and update the local path.

STDIO CONFIG EXAMPLE
[mcp_servers.mcp_cloud_deploy]
command = "node"
args = ["/absolute/path/to/cloudflare-mcp/scripts/start-local.mjs"]
cwd = "/absolute/path/to/cloudflare-mcp"

The local process reads .env from the checkout. Never paste Cloudflare tokens into MCP client config.

04 · Publish

Deploy a local build folder.

Build your app with its normal framework command first. For a local deployment, point dir_path to the output folder containing index.html. React/Vite apps can enable SPA fallback. You can also ask the local server to fetch a public GitHub repository.

PROMPT EXAMPLE
Deploy my website to Cloudflare Pages.
Project name: mystoreabc
Build folder: ./dist
SPA mode: on
I don't have a domain; use the pages.dev URL.

Nested assets are uploaded with their original paths. The result includes a pages.dev URL; attach a domain later if you own one.

05 · Tools and boundaries

Keep credentials and execution local.

  • deploy_to_cloudflare_pages — validates the build output, creates or finds a Pages project and uploads static files.
  • attach_custom_domain — binds a domain and creates a CNAME when its zone and token permissions allow it.
  • list_deployments — lists recent deployments, domains and live URLs.
  • The local server uses stdio and accesses folders on this machine. No hosted endpoint is part of this local flow.
  • Hosted MCP is a separate option; each user authorizes their own Cloudflare account using OAuth.

The MCP does not execute arbitrary build scripts from a repository. Build the app yourself, then upload its static output.
