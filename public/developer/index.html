Hướng dẫn này dành cho developer muốn chạy process MCP riêng trên máy của mình. Server dùng stdio, đọc thư mục local trực tiếp và lấy Cloudflare credentials từ file .env không được commit.

01 · Clone and build

Tải source và build trên máy của bạn.

  1. Cài Node.js 18 trở lên và npm.
  2. Clone repository, cài dependencies, tạo file .env riêng từ mẫu rồi build TypeScript.
TERMINAL · MACOS / LINUX / WINDOWS WSL
git clone https://github.com/hoangtrietdev/cloudflare-mcp.git
cd cloudflare-mcp
npm ci
cp .env.example .env
npm run build

.env nằm trên máy bạn. Không commit hoặc gửi file này lên GitHub. Trên Windows PowerShell, thay lệnh copy bằng Copy-Item .env.example .env.

02 · Cloudflare access

Tạo API Token có quyền tối thiểu.

  1. Đăng nhập Cloudflare Dashboard → My Profile → API Tokens → Create Token.
  2. Dùng template Pages hoặc tạo token có Cloudflare Pages Edit trên đúng account.
  3. Chỉ thêm Zone Read và DNS Edit nếu muốn MCP tự tạo DNS record cho custom domain.
  4. Copy Account ID từ trang tổng quan account Cloudflare, rồi điền cả hai giá trị vào file .env.
.ENV · LOCAL ONLY
CLOUDFLARE_API_TOKEN=your_scoped_api_token
CLOUDFLARE_ACCOUNT_ID=your_32_character_account_id

Dùng API Token, không dùng Global API Key. Giữ .env riêng trên máy và thu hồi token nếu nghi ngờ bị lộ.

03 · MCP client

Trỏ client về local server process.

Thay /absolute/path/to/cloudflare-mcp bằng đường dẫn checkout thật của bạn. Các config mẫu đầy đủ đã có trong thư mục examples/configs/.

Codex

Thêm nội dung examples/configs/codex.toml vào ~/.codex/config.toml. Khởi động lại Codex sau khi lưu.

VS Code

Copy examples/configs/vscode.mcp.json vào .vscode/mcp.json của workspace, cập nhật absolute path và mở lại VS Code.

Claude Desktop

Merge examples/configs/claude_desktop.json vào Claude Desktop MCP config. Trên macOS, file thường ở ~/Library/Application Support/Claude/claude_desktop_config.json.

JetBrains

Trong AI Assistant → Model Context Protocol, import JSON từ examples/configs/jetbrains.json rồi cập nhật absolute path.

CONFIG MẪU · STDIO
[mcp_servers.mcp_cloud_deploy]
command = "node"
args = ["/absolute/path/to/cloudflare-mcp/scripts/start-local.mjs"]
cwd = "/absolute/path/to/cloudflare-mcp"

Process local tự đọc .env trong checkout. Không thêm Cloudflare token vào cấu hình MCP của client.

04 · Deploy

Deploy thư mục local hoặc website từ GitHub.

Build website trước bằng framework bạn dùng. Với thư mục local, gọi tool deploy từ trợ lý AI và trỏ dir_path đến build output. Với repo GitHub, hãy đảm bảo output đã được build và commit lên branch.

PROMPT EXAMPLE
Deploy website của tôi lên Cloudflare Pages.
Project name: mystoreabc
Build folder: ./dist
SPA mode: on

Tool sẽ yêu cầu có index.html, giữ nguyên cây thư mục assets và trả URL .pages.dev. Bạn có thể yêu cầu gắn domain sau khi deploy.

05 · Tools & execution boundaries

Giới hạn rõ ràng, credentials ở local.

  • deploy_to_cloudflare_pages — kiểm tra build output, tạo hoặc tìm Pages project, upload static assets.
  • attach_custom_domain — gắn domain và tạo DNS CNAME nếu token có quyền và zone nằm trong account.
  • list_deployments — liệt kê deployment gần đây, domains và live URLs.
  • Server chạy process local bằng stdio. Không có endpoint hosted nào tham gia vào yêu cầu từ server local.
  • Hosted MCP dành cho người muốn cấu hình endpoint mà không cài server; khi kết nối, mỗi người nhập Cloudflare credentials của riêng họ qua OAuth.

MCP không chạy lệnh build tùy ý trong repo. Hãy tự build app trước; chỉ thư mục output tĩnh được gửi lên Cloudflare Pages.
