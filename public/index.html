Deploy cả website thật, không chỉ một trang mẫu.

MCP đưa build output lên Cloudflare Pages, giữ nguyên cây thư mục để hình ảnh, font, CSS và JavaScript tải đúng. Yêu cầu deploy website từ GitHub, rồi chọn URL pages.dev hoặc nối domain riêng.

▧

Landing page nhiều hình ảnh

Upload toàn bộ thư mục build với assets và đường dẫn gốc được giữ nguyên. Hợp với landing page, portfolio, tài liệu và cửa hàng tĩnh.

⌘

React, Vite và SPA

Deploy output đã build sẵn, bật SPA fallback để các route phía client hoạt động khi tải lại. SSR và backend Node cần dịch vụ runtime riêng.

◎

Có hoặc chưa có domain

Bắt đầu bằng URL pages.dev miễn phí. Khi sẵn sàng, yêu cầu gắn domain bạn sở hữu và nhận trạng thái DNS/SSL.

Thiết lập một lần

Kết nối MCP. Bạn vẫn giữ quyền kiểm soát.

Thêm endpoint bên dưới vào MCP client. Trong bước cấp quyền, bạn nhập credentials Cloudflare của chính mình và chọn quyền cần thiết.

01

Thêm endpoint MCP

Chọn Codex, VS Code, Claude hoặc JetBrains rồi copy cấu hình kết nối từ xa.

02

Nhập credentials Cloudflare của bạn

Trang kết nối yêu cầu Account ID và API Token. Cần quyền Pages Edit; thêm Zone Read và DNS Edit nếu muốn tự cấu hình DNS.

03

Yêu cầu deploy tự nhiên

Ví dụ: “Deploy repo https://github.com/acme/store tên mystoreabc, output_dir dist, bật SPA.” Repo cần public và có sẵn build output.

Codex · MCP từ xa
◈Không dán token vào file cấu hình. MCP client mở bước OAuth để bạn nhập an toàn; có thể thu hồi quyền bất cứ lúc nào.
