↗

Landing page nhiều ảnh

Đưa cả thư mục build lên Pages; các nested assets tiếp tục đúng đường dẫn. Phù hợp website giới thiệu, portfolio, tài liệu và cửa hàng tĩnh.

⌘

React / Vite SPA

Bật chế độ SPA để các đường dẫn client-side quay về index.html. SSR và backend Node cần runtime riêng, không phải static upload.

◎

Domain riêng khi cần

Dùng pages.dev ngay hoặc yêu cầu gắn domain đã sở hữu. DNS có thể tự cấu hình nếu zone ở Cloudflare, nếu không sẽ có record hướng dẫn.

Kết nối trợ lý AI

Cấu hình MCP, rồi deploy bằng chat.

Chọn ứng dụng bạn đang dùng để xem cấu hình kết nối. Phần cài đặt, chạy và tự host server nằm riêng trong Developer Docs.

01

Thêm server MCP

Chọn client và thêm endpoint remote. Trong trang ủy quyền, nhập Account ID cùng API Token riêng; token không nằm trong cấu hình MCP.

02

Cho phép Cloudflare

Chỉ cấp quyền Pages cần thiết. Quyền DNS chỉ cần thiết khi bạn muốn tự tạo record cho domain.

03

Yêu cầu deploy

Ví dụ: “Deploy repo https://github.com/acme/store tên mystoreabc, output_dir là dist, bật SPA”. Repo online cần public và chứa build output sẵn.

Codex · cấu hình MCP từ xa


Custom domain
Chưa có domain? Không sao.
Mỗi Cloudflare Pages project có URL pages.dev để bạn dùng ngay. Khi có domain, MCP có thể gắn domain vào project và hướng dẫn cấu hình DNS chính xác.
Ví dụ: thêm www.example.com dạng CNAME trỏ đến mystoreabc.pages.dev. SSL hoạt động sau khi domain được xác minh và DNS cập nhật.
