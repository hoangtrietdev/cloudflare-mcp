One-time setup

Connect MCP. Keep control of your account.

Add the hosted MCP endpoint to your client. During authorization, enter your own Cloudflare credentials and grant only the permissions you need.

01

Add the MCP endpoint

Choose Codex, Claude, VS Code or JetBrains and copy the remote connection details.

02

Authorize Cloudflare

Enter your Account ID and API Token in the secure connection flow. Pages Edit is required; Zone Read and DNS Edit are only needed for automatic DNS.

03

Ask for your deployment

Example: “Deploy my public GitHub repo as mystoreabc from dist, enable SPA routing.” Online mode expects prebuilt public GitHub output.

Cloudflare Pages gives your deployment a pages.dev URL. If you own a custom domain, the MCP can bind it and check for a matching Cloudflare DNS zone.
If DNS is hosted elsewhere, you’ll get the exact CNAME record to add at your provider. Cloudflare issues SSL after DNS and domain verification complete.
