Quyền riêng tư

Thông tin bạn cần biết.

Chính sách này áp dụng cho hosted MCP khi được vận hành bởi maintainer dự án. Bản tự host do người vận hành tự quản lý dữ liệu.

Dữ liệu được xử lý

  • Thông tin grant OAuth và kết nối MCP.
  • Cloudflare Account ID và API Token bạn nhập trên trang HTTPS cấp quyền.
  • URL repository GitHub public, branch và yêu cầu deploy gửi tới tool.

Cách sử dụng

Token được xác minh rồi dùng để gọi Cloudflare API thực hiện Pages, DNS và xem deployment theo yêu cầu. Ứng dụng mã hóa API Token bằng AES-256-GCM trước khi lưu OAuth grant và chỉ giữ hash của access/refresh token trong Upstash Redis. API Token không được đưa vào tool output hay application logs. Vercel server chỉ lấy archive public từ GitHub (api.github.com và codeload.github.com). Archive được xử lý trong request; Cloudflare Pages nhận các tệp được deploy.

Token được truyền qua HTTPS đến Vercel Function và lưu mã hóa AES-256-GCM trong Upstash Redis. Chỉ kết nối nếu bạn tin cậy operator của endpoint. Hãy dùng API Token riêng với quyền tối thiểu; không dùng Global API Key.

Lưu trữ và thu hồi

Access token hết hạn sau 1 giờ; refresh grant có hạn 30 ngày và được xoay khi sử dụng. Grant OAuth được giữ trong Upstash Redis cho đến khi bạn thu hồi kết nối hoặc hết TTL. Ngắt/revoke ủy quyền MCP để xóa grant; đồng thời thu hồi API Token trong Cloudflare để vô hiệu hóa credential. Deployment và DNS records được lưu trong tài khoản Cloudflare của bạn theo chính sách của Cloudflare.

Chia sẻ dữ liệu và liên hệ

Dữ liệu không được bán hay chia sẻ với dịch vụ quảng cáo hoặc analytics. Vercel hosts the application, Upstash stores OAuth data, and Cloudflare processes account operations. Báo cáo sự cố bảo mật theo hướng dẫn trong SECURITY.md. Mã nguồn hosted server mở tại GitHub.
